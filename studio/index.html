Sign in with your GitHub access token to edit the site.

How do I get a token?
  1. Sign in to GitHub as upliftdigitalpartners (the account that owns the site).
  2. Open Settings → Developer settings → Fine-grained tokens → Generate new token.
  3. Name it “Studio”, choose an expiry, and under Repository access pick Only select repositories → Sharifadornment.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Generate, copy the token, and paste it above. Keep it private — anyone with it can edit the site.
